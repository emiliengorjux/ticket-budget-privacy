Suppression des données — Ticket Budget

Supprimer vos données

Ticket Budget stocke les données de dépenses et les autres informations saisies dans l'application localement sur votre appareil.

Vous pouvez supprimer ces données directement depuis l'application : Profil → Effacer mes données.

Cette action permet de supprimer les données enregistrées localement par Ticket Budget sur votre appareil.

Compte utilisateur

Ticket Budget ne nécessite pas de création de compte utilisateur. Il n'existe donc pas de compte personnel à supprimer à distance.

Données des services tiers

Certains services tiers, notamment Google AdMob, peuvent traiter des données conformément à leurs propres politiques de confidentialité. La suppression des données associées à ces services est gérée selon les procédures proposées par leurs fournisseurs respectifs.
